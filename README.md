# Контроль расходов

Новый отдельный Android-проект. Не является продолжением Chekskan.

Приложение: «Контроль расходов».

В меню нет раздела «Настройки».

Основной сценарий: главный экран расходов → камера или галерея → отдельный полноэкранный экран чека → русское OCR → проверка позиций и фактически уплаченных сумм → сохранение → возврат в журнал расходов.

Каждая покупка хранит свою валюту отдельно. Разные валюты не складываются без явного пересчёта.

Для сборки откройте проект в Android Studio и выполните Build → Build APK(s).
